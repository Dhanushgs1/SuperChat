Select a chat to read it.

⭐ Keep it, 🗑️ delete it, or ✨ extract the valuable knowledge from it.

Send this chat to Claude?

Extract valuable knowledge sends this conversation to Claude (Anthropic) under your Claude Team plan. Passwords, keys, tokens, emails, phone numbers and IPs are masked first, and tool logs are cut to one line each. Claude runs with no tools, so it can only read and reply.

Only approved knowledge is saved to Obsidian. You review everything first.

Delete forever?

This permanently removes the chat from SuperChat:

  • It disappears from All, Kept and Deleted and will not come back when SuperChat scans for new chats.
  • Its unapproved knowledge drafts are deleted.

This does not delete:

  • The original Claude Code, Cursor, Codex, Gemini or Hermes chat files.
  • CASS's search index and its copy of the chat.
  • Knowledge you already approved (those notes stay in Obsidian; delete them there if needed).
  • Database backups in superchat\data and the audit log entry for this action.
